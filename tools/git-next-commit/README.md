# git next commit

This tool is a git sub command that will checkout to next commit in specific branch you specified (or default branch).

Installation commands are easy as just copying a simple bash script to a directory on $PATH variable.
for example:

```shell
sudo cp git-next-commit /usr/bin/
```

Use `git next-commit -h` to see its help and documents.
I don't want maintain docs also in README.md :)) help command is sufficient.

# Learn X

It's a general roadmap for X and you can copy it for a specific learnable thing
and tailor these steps and roadmap per-case. This is a guide to break tasks
for a specific case.

## About X

- Learn about who introduced X and talked about it first
- Learn initial needs and problems that X solved
- List main relevant key concepts and use cases
- List all use cases and related concepts
- Discover and learn related things and get rid of unclear areas
- Connect with people related to X, connect on LinkedIn, find communities, find people
- Find the best document references
- Find books and collect them

## Fundamentals

- Discovering all topics and concepts of X and even skim their names
- Basic parts of the document/reference
- Explore video content (optional)
- Clone and analyze overall related project/source codes if they exist
- Explore and learn basic interfaces (manpage, --help, etc)
- Start toy projects and implement examples
- Complete reading tutorials of the document/reference and exercise with them

## Deep diving on concepts

This section is a loop for aggregating knowledge.
Consider each stage as an independent way of learning like a service.
Knowledge should pass from one service to the next service and keep the state.

- Read references and advanced concepts
- Read other blog/references for understanding the official reference
- Read source code for better learning
- Ask questions of people
- Note problems that you believe are flaws in X, try to understand and even fix them
- Deep dive in related tools and ecosystem
- Note and mark related concepts to X that you should know

## Engineering mindset

- Design and find problems, exercises to solve them using X
- Talk about what problems X will solve and how, mock them
- Talk about what problems X has and talk about them!
- Find constraints, where X is brilliant and document them for future
- Understand and compare with similar ones and master trade-off analyzing

## Be a part of X

- Subscribe to news and new events of X
- Build relationships with X people
- Contribute and help to X open source projects or community
- Read books, talk to author, ask questions and even suggest to improve book
- Read commit messages, PRs, issues daily or in specific planned period

# LearnX

This project will help me and others to learn anything they want. You can use its
roadmap and also tools like AI agents, skills, documents. The most important thing
for this project, which also is its goal, is tracking your path and progress for learning
a specific case. We developed a general roadmap for learning anything in `roadmap/general.md`
and it's possible and reasonable to copy and tailor it for more roadmap types.

For example, a roadmap for a tool, or something that is built with code. Roadmap for concepts,
fields, and anything that needs a more tailored general roadmap.

## Goal

Pure roadmaps, regardless of context and what is planned for learning, are located in `roadmap/`
and the `x/` directory contains usernames and the name of what they want to learn.
This project will track progress of every contributor if they want.

New users can read and learn from `/x/*/`, previously written docs and notes to start
their path. The project wants to collect and develop more tools for learning, providing more
scripts, tools, AI tools, agents and documents.

Also write documentation for newly found tools, references and anything you believe will help
others to learn better and faster with higher quality in the `docs` directory.

## Docs

In `docs` you can write and read what contributors believe is good for learning new things.
For example tools to analyze a codebase, search references, understanding or summarizing
long references, platforms for tracking and learning.

# NATS.io Key People & Company Profiles

## Project Overview

- **Project:** NATS.io - High-Performance Cloud Native Messaging System
- **Repository:** github.com/nats-io/nats-server
- **Organization:** nats-io (maintained by Synadia Communications)
- **Primary Language:** Go (with clients in 40+ languages)
- **Founded:** 2009 (initial code), 2010 (first public release)
- **License:** Apache-2.0
- **CNCF Status:** Incubating project

## Company: Synadia Communications

**Role:** Primary commercial entity behind NATS.io
**Founded:** 2017 (though NATS predates the company)
**Headquarters:** Los Angeles, CA, USA
**Website:** [synadia.com](https://www.synadia.com)
**GitHub:** [github.com/synadia-io](https://github.com/synadia-io)
**Twitter:** [@synadia](https://twitter.com/synadia)
**LinkedIn:** [Synadia Communications](https://www.linkedin.com/company/synadia-communications/)
**Contact:** info@synadia.com

**Company Description:**
Synadia Communications is the primary commercial entity behind NATS.io, providing enterprise support, cloud services (Synadia Cloud/NGS), and commercial offerings built on NATS. The company was founded by Derek Collison after the successful sale of Apcera to Ericsson. Synadia houses almost all NATS maintainers and drives the development of the open-source project.

**Funding:** Backed by leading VCs including Forgepoint Capital, True Ventures, Bold Capital Partners, LDVP, Singtel, Accenture, and Samsung Next.

## Key Insights About NATS.io Team

1. **Strong Company Backing:** Unlike many open-source projects, NATS has Synadia as a dedicated commercial entity with significant VC funding
2. **Long-term Commitment:** Most maintainers have been with the project for 5+ years, showing stability
3. **Diverse Expertise:** Team includes messaging veterans from TIBCO, cloud pioneers from Google/VMware, and network engineers
4. **Global Distribution:** Team members in Miami, Denver, San Francisco, Minnesota, Malta, Poland, Netherlands, UK, Arizona, Baltimore, Texas, Pennsylvania, California, and other locations
5. **Active Development:** Regular commits, blog posts, conference talks, and community engagement
6. **Strong Community:** 11K+ Slack members, 20K+ GitHub stars, 40+ client libraries
7. **CNCF Incubating:** Project is part of the Cloud Native Computing Foundation ecosystem
